
# Simple Math Library

A simple reusable JavaScript library for basic mathematical operations.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Division-by-zero validation
- Square of a number

## Usage

Include math-utils.js in your HTML file:

    <script src="math-utils.js"></script>

Example:

    SimpleMath.add(10, 5); // Returns 15
